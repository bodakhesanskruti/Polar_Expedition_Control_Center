# Expedition Control Center - Frontend

React/Vite frontend for the SIH **Integrated Polar Expedition Logistics and Asset Management System**.

## Run

```powershell
npm install
npm run dev
```

Open http://localhost:5173

The backend must be running at `http://127.0.0.1:8000`.

## Environment

Copy `.env.example` to `.env` if your backend uses another host/port.

## Pages

- Mission Dashboard
- Live Operations Map
- Cargo Tracking
- Inventory Management
- Personnel Management
- Alert Center
- Emergency Response
